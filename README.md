TasteNow pomaga szybko znaleźć otwarty lokal w pobliżu, dopasowany do budżetu i preferencji.

## Pierwszy cel

W ciągu 2–3 dni użytkownik powinien potwierdzić następujący MVP:

1. Udostępnia lokalizację.
2. Ustawia budżet i jedną podstawową preferencję.
3. Otrzymuje kilka otwartych lokali posortowanych pod kątem czasu dojścia i dopasowania.
4. Otwiera szczegóły, aktualne godziny oraz mapę.
